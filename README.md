# MecanAI - Diagnóstico Veicular Inteligente 🚗⚡

App revolucionário para diagnóstico de problemas em veículos usando Inteligência Artificial.

## 🎯 Sobre o Projeto
Sistema inteligente que analisa problemas automotivos através de:
- 📹 Vídeos do veículo
- 🖼️ Fotos detalhadas  
- 🎧 Áudios descritivos
- 📝 Textos específicos do cliente

## ✨ Funcionalidades
- Diagnóstico com IA - Análise precisa e cirúrgica
- Multiplataforma - Funciona em qualquer dispositivo
- Interface Intuitiva - Fácil de usar para mecânicos e clientes
- Relatórios Detalhados - Laudos completos dos problemas

## 🛠 Tecnologias
- Progressive Web App (PWA)
- HTML5, CSS3, JavaScript
- Service Worker para funcionamento offline

## 🚀 Como Usar
1. Acesse o app
2. Insira vídeos, fotos ou áudios do problema
3. Descreva os sintomas específicos
4. Receba o diagnóstico inteligente da IA
